# 香港智慧城市地圖

打開網站就是一幅可拖曳、可放大的香港地圖。地圖上有十條港鐵重鐵綫，以及運輸署的交通快拍點。

- 點選車站，查看該綫最多四班即將到站的列車。
- 點選快拍點，查看該處最新相片。
- 沒有班次、相片載入失敗，或官方表示暫時未能提供服務時，畫面會直接說明。

底圖使用 [OpenFreeMap](https://openfreemap.org/) 的公開服務，不用登記，也不用鑰匙。

## 資料從哪裡來

| 畫面內容 | 來源 |
| --- | --- |
| 街道底圖 | OpenFreeMap Liberty 樣式 |
| 車站名稱和行車次序 | 港鐵「港鐵綫（輕鐵除外）及車站」 |
| 路軌彎度 | OpenStreetMap 港鐵路綫，與底圖同一地圖資料 |
| 到站班次 | 港鐵實時列車服務資訊，點選時才查詢 |
| 車站位置 | 地政總署地理位置搜尋，建立時轉成經緯度 |
| 快拍點和相片 | 運輸署交通情況快拍圖像 |

輕鐵和高鐵不在這份到站資料內，所以地圖沒有畫它們。馬場站有座標，也會查班次，但日常東鐵綫不會繞經它。東鐵綫在上水分岔往羅湖和落馬洲，將軍澳綫在將軍澳分岔往康城。

## 本機運行

需要 Node.js 22.12 或更新版本。

```bash
npm install
npm run dev
```

開發伺服器位址是 `http://127.0.0.1:4731`。

重新整理內置的車站和快拍清單前，先安裝 Python 套件 `pyproj`：

```bash
pip install pyproj
python3 scripts/build_network.py
```

這個指令會再次讀取官方檔案。車站座標有本地快取，避免短時間內大量查詢地政總署。

## 驗收時可以這樣看

1. 打開後應看到香港，可以拖曳和放大。
2. 圖例有十條港鐵綫，點一下可以暫時隱藏。
3. 搜尋「中環」，查看往柴灣和往堅尼地城的班次。
4. 點金鐘，分綫查看港島綫、荃灣綫、南港島綫和東鐵綫。
5. 點馬場。若當天沒有賽事，畫面會寫明官方成功但沒有班次。
6. 放大後點一個琥珀色快拍點，例如紅磡海底隧道一帶，查看相片。
7. 用窄螢幕查看時，資料面板在下方，地圖仍留在上方。

## 正式發佈

驗收通過之後，才發佈到 Cloudflare Workers 免費方案，使用 `workers.dev` 網址。預計費用是 0 美元：網站是靜態檔案，到站和相片由瀏覽器直接向政府來源讀取，不使用付費資料庫或自訂網域。

```bash
npm run build
npx wrangler deploy
```

部署需要你自己的 Cloudflare 免費帳戶登入。Workers 付費方案最低每月 5 美元；以這個靜態網站的做法，不會用到。
